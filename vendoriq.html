How it works

VendorIQ uses a RandomForest classifier trained on procurement KPI data. All features are scaled with StandardScaler before inference. The model uses probability-weighted scoring across High/Medium/Low classes; a heuristic fallback runs automatically if model files are missing.

RandomForestClassifier n_estimators=200 StandardScaler
POST
/predict

Score a vendor and persist the result to SQLite. Returns risk_score and risk_category.

GET
/vendors

Fetch all vendor records ordered by most recent. Powering dashboard stats and the vendor table.

DELETE
/vendor/:id

Remove a vendor record by ID. Returns 404 if not found. Immediately reflected in the UI.

GET
/health

Returns {"status":"ok"} when the API is running. Polled every 10 seconds by the status indicator.
